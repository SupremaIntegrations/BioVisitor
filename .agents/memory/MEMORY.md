- [Enroller devices architecture](enroller-devices.md) — devices stored in Redis `enrollers:{tenantId}`, device list cached `bv:devices:{tenantId}` 5min, BioStar session cached `bv:bsession:conn:{connId}` 25min.
- [BioStar X monitoring LAN restriction](biostar-monitoring-lan-restriction.md) — monitoring API (scan_picture/events) requires LAN access; 403 code 20 by:web via ngrok/remote is expected.
- [Audit log userName resolution](audit-log-username-resolution.md) — userName for audit trail is auto-resolved from userId centrally, not per call-site; don't add manual name lookups in new logUserAction call sites.
- [Per-tenant settings pattern](per-tenant-settings-pattern.md) — Redis-backed per-tenant config (key `{feature}:{tenantId}`) is the established convention for admin-configurable settings, not DB tables.
- [BioStar WS event field shapes](biostar-ws-events.md) — user_id/device_id in WS events can be nested objects or raw values; always use the multi-shape fallback chain.
- [Deferred/delayed action re-check](deferred-action-recheck.md) — for setTimeout-scheduled actions from events, re-fetch entity and re-validate status right before executing, not at schedule time.
- [Redis dev persistence across restarts](redis-dev-persistence.md) — Redis had no persistence config, so all settings (exit devices, enrollers) were wiped on every workflow restart; now fixed via `--dir`/`--save` in start.sh.
- [BioStar events/search schema & granted-event codes](biostar-events-search-schema.md) — datetime range needs ONE condition with both bounds; "granted" spans 0x13xx (IDENTIFY 1:N) AND 0x10xx (VERIFY 1:1, e.g. card) — checking only 0x13 misses all card-based access.
- [Turbopack cache corruption & race condition](turbopack-cache.md) — stale .next cache makes Turbopack accept TCP connections but never respond; fix: rm -rf .next + restart. Backend needs 15s head start before Next.js starts.
- [BioStar device capability detection](biostar-device-capability.md) — POST /api/devices/capability returns empty rows; GET /api/devices omits type_id.name; use device NAME as model source + precise prefix map. Redis keyPrefix "bv:" makes actual keys "bv:bv:*" — clear with that prefix.
- [BioStar 2 scan_card response shape](biostar-scan-card-shape.md) — FaceStation F2: card_id at data.Card.card_id (NOT nested in card_type); card_type.type numeric: "0"=Unknown/CSN, "1"=CSN (Mifare/HID), "2"=Wiegand. card_type.id="0" for CSN family.
- [Multi-tenant seed & JWT tenantId stale](multi-tenant-seed-jwt.md) — re-seed creates duplicate tenant if existing tenant name differs; JWT payload tenantId goes stale after DB migration; validateJwtPayload must return user.tenantId from DB, not payload.tenantId.
- [NestJS backend hot-reload gap](nestjs-hot-reload.md) — nest start --watch compiles TS but PID stays alive; edited .ts files don't reload until workflow is restarted; always restart workflow after backend changes to confirm new code is running.
